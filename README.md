## 💅 About The Project

A **modern, fully responsive salon website** built with pure HTML, CSS, and JavaScript — designed to showcase services, client testimonials, and contact details in a stylish, premium format. Powered by **GSAP animations** and **Swiper.js sliders** for a polished, luxury feel.

> 🌸 Crafted as a professional portfolio & learning project — blending elegant UI design with functional frontend development.

<br/>

<div align="center">

| 🎨 Design | ⚡ Animations | 📱 Responsive | 📞 Contact |
|:---:|:---:|:---:|:---:|
| Premium custom branding & fonts | GSAP fade-up transitions | Seamless desktop & mobile | Call & WhatsApp CTAs |

</div>

## 🚀 Getting Started

**1. Clone the repository**

```bash
git clone https://github.com/aryansengar007/salon-website.git
```

**2. Navigate into the project folder**

```bash
cd salon-website
```

**3. Launch in your browser**

```bash
# Option A — Open directly:
open index.html

# Option B — Use VS Code Live Server for hot reload:
# Right-click index.html → "Open with Live Server"
```

> ✅ No npm install. No build step. No configuration needed.
